<h1 id="配置与命令" data-toc-id="配置与命令">配置与命令</h1>
<p>本页面向服务器管理员与整合包作者，说明 SmartPhone 的 NeoForge 通用配置、应用禁用列表和管理命令。所有 <code>/smart_phone</code> 子命令都要求执行者具有 2 级权限。</p>

<h2 id="通用配置" data-toc-id="通用配置">通用配置</h2>
<p>SmartPhone 注册的是 NeoForge 通用配置，配置文件名为 <code>smart_phone_config.toml</code>。文件的具体存放位置遵循 NeoForge 对客户端与服务器通用配置的标准规则。</p>
<pre language="toml" isclosed="false"><code class="language-toml">[config]
phoneMarginLeft = 0.0
phoneMarginTop = 0.0
heldPhoneMode = true

[apps]
disabledApps = &quot;smart_phone:camera,smart_phone:phone_call&quot;</code></pre>
<table data-type="custom-table" data-with-header-row="true" style="min-width: 100px;">
  <tbody>
    <tr>
      <th>字段</th>
      <th>默认值</th>
      <th>说明</th>
    </tr>
    <tr>
      <td>config.phoneMarginLeft</td>
      <td>0</td>
      <td>手机界面水平偏移百分比，范围为 -100 到 100；手持模式下右手也会随之移动</td>
    </tr>
    <tr>
      <td>config.phoneMarginTop</td>
      <td>0</td>
      <td>手机界面垂直偏移百分比，范围为 -100 到 100；手持模式下右手也会随之移动</td>
    </tr>
    <tr>
      <td>config.heldPhoneMode</td>
      <td>true</td>
      <td>切换到主手手机时立即举起右手和手机；原版物品画面隐藏，左边距和上边距微调最终停留位置</td>
    </tr>
    <tr>
      <td>apps.disabledApps</td>
      <td>空字符串</td>
      <td>逗号分隔的应用注册名；被列出的应用不会显示或自动安装</td>
    </tr>
  </tbody>
</table>

<h2 id="指定玩家手机配置" data-toc-id="指定玩家手机配置">指定玩家手机配置</h2>
<p>使用 <code>/smart_phone config &lt;玩家名、UUID或角色名&gt; &lt;参数&gt; &lt;值&gt;</code> 修改指定手机。指令要求 2 级权限，也可从服务器控制台或命令方块执行。目标支持服务器已有玩家或已注册虚拟角色；UUID 可用于已有离线玩家。配置跟随手机绑定主人存储，保存后立即更新当前持有者的手机。</p>
<pre language="mcfunction" isclosed="false"><code class="language-mcfunction">/smart_phone config Dev wallpaper smart_phone:textures/ui/default_wallpaper.png
/smart_phone config Dev locked true
/smart_phone config Dev hide_date true
/smart_phone config Dev hide_status_icons true
/smart_phone config Dev hide_owner_name true
/smart_phone config Dev hide_lock_icon true</code></pre>
<table data-type="custom-table" data-with-header-row="true" style="min-width: 100px;">
  <tbody>
    <tr><th>参数</th><th>值</th><th>效果</th></tr>
    <tr><td>wallpaper</td><td>命名空间:纹理路径</td><td>修改手机壁纸，图片需要存在于客户端模组或资源包中</td></tr>
    <tr><td>locked</td><td>true / false</td><td>启用或解除管理员拦截，默认 false</td></tr>
    <tr><td>hide_date</td><td>true / false</td><td>隐藏或显示待机大时间与顶部时间，默认 false</td></tr>
    <tr><td>hide_status_icons</td><td>true / false</td><td>一起隐藏或显示信号、电量图标，默认 false</td></tr>
    <tr><td>hide_owner_name</td><td>true / false</td><td>隐藏或显示待机页的手机主人名称，默认 false</td></tr>
    <tr><td>hide_lock_icon</td><td>true / false</td><td>隐藏或显示底部锁图标，不改变解锁权限，默认 false</td></tr>
  </tbody>
</table>
<p>拦截后待机页显示闭合锁，移除“向上滑动以解锁”提示，上滑和密码均无法解锁。正在使用的应用或相机会返回待机页。执行 <code>/smart_phone config Dev locked false</code> 可解除拦截，之后仍遵循原有密码设置。隐藏选项改为 <code>false</code> 可恢复显示。</p>
<p>这五个开关也可以在手机数据编辑器“基础”页修改并预览。普通手机设置保存不会覆盖管理员开关。编辑器可以进入被拦截手机的聊天、消息内容预览，不必先解除拦截；返回待机预览后仍遵循拦截设置。离线玩家的修改会持久保存，下次使用手机时生效。</p>

<h2 id="虚拟角色手机" data-toc-id="虚拟角色手机">虚拟角色手机</h2>
<p>地图作者可以预先注册虚拟角色，不需要知道之后游玩者的玩家 ID。以下指令需要 2 级权限；中文或包含空格的名称使用双引号。</p>
<pre language="mcfunction" isclosed="false"><code class="language-mcfunction">/smart_phone character register "张三"
/smart_phone editor "张三"
/smart_phone config "张三" locked true
/smart_phone bind "张三"
/give @s smart_phone:phone[smart_phone:phone_owner="张三"]</code></pre>
<p>先注册角色，再打开编辑器预设内容。绑定指令修改主手手机；give 示例则创建一部组件主人为“张三”的手机。名称支持 1–64 个字符，不能使用 UUID、控制字符或首尾空格。重复注册不会覆盖原有资料，未注册角色也不会被当作真实玩家自动创建。名称解析优先匹配已注册角色；真实玩家与角色重名时，使用玩家 UUID 指定真实玩家。</p>
<p>待机页显示“张三的手机”，新建的主人消息、预设聊天回复和公共聊天发送者使用“张三”，不会显示持有者的名称。角色手机副本共享资料与密码。无主人组件的手机仍在首次打开时绑定实际持有者；已有玩家手机和 UUID 存档继续兼容，无需手动迁移。</p>

<h2 id="管理员命令" data-toc-id="管理员命令">管理员命令</h2>
<table data-type="custom-table" data-with-header-row="true" style="min-width: 100px;">
  <tbody>
    <tr>
      <th>命令</th>
      <th>作用</th>
    </tr>
    <tr>
      <td>/smart_phone open</td>
      <td>向执行命令的玩家打开自己的手机资料</td>
    </tr>
    <tr>
      <td>/smart_phone bind &lt;玩家名、UUID或角色名&gt;</td>
      <td>将执行者主手手机绑定到目标玩家或虚拟角色</td>
    </tr>
    <tr>
      <td>/smart_phone editor [玩家名、UUID或角色名]</td>
      <td>打开手机数据编辑器；省略目标时编辑主手手机绑定主人，没有绑定则编辑自己</td>
    </tr>
    <tr>
      <td>/smart_phone reload</td>
      <td>删除执行者保存的手机资料，下次打开时重建默认内容</td>
    </tr>
    <tr>
      <td>/smart_phone message send</td>
      <td>向一个或多个玩家发送官方消息</td>
    </tr>
  </tbody>
</table>
<p>绑定命令接受本服已有玩家的名称或 UUID，也接受已注册虚拟角色名。输入玩家名称时，还需要服务器玩家缓存能够解析该名称；它不会对任意名字猜测离线模式 UUID。绑定后物品提示会显示手机主人名称；持有这部手机的玩家可修改目标手机资料。启用六位密码后必须先通过密码验证，服务器会在每次保存时检查手机归属与解锁授权。</p>
<p>手机数据编辑器的“基础”页可直接设置解锁密码：输入框只接受数字，最多 6 位，保存时必须恰好 6 位，允许以 0 开头。已有密码只存摘要，因此不会回填原数字；留空不修改会保留，点击“清除密码”并保存可关闭密码。设置或更换无需旧密码，保存后立即应用；新密码会使当前持有者重新锁定手机。密码格式无效时整份草稿都不会保存。</p>
<p>左侧交互预览、右侧参数页、日期选择与预设聊天的操作见<a href="?file=&quot;45-管理.手机数据编辑器.md&quot;">手机数据编辑器</a>。</p>
<p>发送官方消息的完整语法如下：</p>
<pre language="mcfunction" isclosed="false"><code class="language-mcfunction">/smart_phone message send &lt;targets&gt; &lt;title&gt; &lt;body&gt;</code></pre>
<p><code>targets</code> 使用玩家目标选择器；<code>title</code> 是单个字符串参数，包含空格时应加引号；<code>body</code> 会读取剩余的整段命令文本。成功发送后，目标玩家会收到通知并可在“消息”应用内查看。</p>

<div type="warning" data-type="admonition" data-admo-type="warning">
  <div data-type="admonition-title">reload 会清除个人手机资料</div>
  <div data-type="admonition-content">
    <p><code>/smart_phone reload</code> 不是热重载配置。它会移除执行者的 PhoneInfo 记录及手机密码，因此可能清除壁纸、时间设置、已安装应用、图标顺序、记事本和手机内官方消息。执行前请确认目标玩家已备份需要保留的内容。</p>
  </div>
</div>

<h2 id="服务端保存数据" data-toc-id="服务端保存数据">服务端保存数据</h2>
<p>服务器加载主世界时会初始化手机资料、聊天室和好友关系的 SavedData。备份世界存档时，这些数据会随主世界数据一并备份；迁移服务器时应完整迁移相应世界存档。</p>
