<h1 id="手机数据编辑器" data-toc-id="手机数据编辑器">手机数据编辑器</h1>
<p>手机数据编辑器供管理员和地图作者预设指定主人的手机。内容直接读取服务器保存的手机资料，修改先留在编辑器草稿中；点击“保存并生效”后写回服务器，不需要打开工程文件或导入 NBT 文件。打开编辑器需要 2 级命令权限。</p>

<h2 id="选择目标并打开" data-toc-id="选择目标并打开">选择目标并打开</h2>
<pre language="mcfunction" isclosed="false"><code class="language-mcfunction">/smart_phone editor
/smart_phone editor Dev
/smart_phone character register "张三"
/smart_phone editor "张三"</code></pre>
<p>省略目标时，编辑主手手机绑定的主人；主手手机没有绑定主人时编辑自己。也可以指定服务器已知的玩家名、玩家 UUID，或已注册的虚拟角色名。虚拟角色必须先注册；这样可以在不知道未来游玩者玩家 ID 的情况下制作预设手机。创建角色手机的完整步骤见<a href="?file=&quot;50-管理.配置与命令.md&quot;#虚拟角色手机">虚拟角色手机</a>。</p>

<h2 id="预览与界面尺寸" data-toc-id="预览与界面尺寸">预览与界面尺寸</h2>
<p>编辑器左侧是可交互的手机预览，右侧是参数页。可以在左侧滑动、打开应用、进入聊天或消息列表，并点击要修改的会话或消息；右侧随选中对象显示对应字段。拖动中间的分隔线可以改变预览和参数区域的宽度。“返回待机预览”可重新查看锁屏效果。</p>
<p>顶部“界面尺寸”支持自动档和数字档，数字越大，编辑器内的文字与控件越大。该设置只影响手机数据编辑器，退出后恢复游戏原本的 GUI 缩放，不改变编辑器外的手机尺寸。客户端会单独记住该编辑器尺寸。</p>

<h2 id="制作预设聊天" data-toc-id="制作预设聊天">制作预设聊天</h2>
<div currentstep="0" data-type="steps">
  <div data-type="step-item">
    <div data-type="admonition-title">创建会话</div>
    <div data-type="admonition-content"><p>进入“聊天”页，在右下角点击会话的“+”创建频道，或点击“+ 好友”创建预设好友。预设好友的玩家 ID 可以是虚构名称，不要求该玩家真实存在。</p></div>
  </div>
  <div data-type="step-item">
    <div data-type="admonition-title">选中会话</div>
    <div data-type="admonition-content"><p>在左侧手机的频道或好友列表点击会话。右侧显示当前会话名称；预设好友还可修改好友玩家 ID。会话的“−”会删除当前选中的会话。</p></div>
  </div>
  <div data-type="step-item">
    <div data-type="admonition-title">编辑单条消息</div>
    <div data-type="admonition-content"><p>用消息的“+”创建记录，再点击左侧手机中的某条消息。右侧只显示这条记录的发送者、是否由手机主人发送、头像玩家 ID、日期时间和正文。消息的“−”删除当前选中的记录。</p></div>
  </div>
  <div data-type="step-item">
    <div data-type="admonition-title">加入图片</div>
    <div data-type="admonition-content"><p>选中消息后点击“从相册选择图片”，在左侧手机图册中挑选已有照片，也可以移除已选图片。保存的是图片缩略图数据；可与文字组成图文消息。</p></div>
  </div>
</div>
<p>“头像玩家 ID”接受最多 16 位英文字母、数字或下划线。填入正版 Java 玩家用户名后，这条消息可显示该账号的皮肤头像；该账号不必在线。留空时使用发送者原头像。头像来源与消息显示名称相互独立。预设聊天的更多行为见<a href="?file=&quot;30-功能.社交与聊天.md&quot;#预设会话">预设会话</a>。</p>

<h2 id="密码与保存" data-toc-id="密码与保存">密码与保存</h2>
<p>“基础”页的解锁密码框只接受数字，最多六位；填写新密码后必须正好六位才能保存，允许前导 0。已有密码只在服务端保存摘要，编辑器不会显示原数字：不输入新密码会保留原密码；点击“清除密码”并保存可移除它。管理员在编辑器中设置或更换密码无需输入旧密码。</p>
<p>右上角点击“保存并生效”后，服务器会验证目标与密码格式，将整份草稿保存到该手机主人名下，并更新正在使用这部手机的玩家。未保存的修改在关闭编辑器时会弹出放弃确认。若保存失败，编辑器会保留草稿并显示失败状态，可检查目标与密码后重试。</p>
<div type="important" data-type="admonition" data-admo-type="important">
  <div data-type="admonition-title">保存的是手机主人的资料</div>
  <div data-type="admonition-content"><p>真实玩家手机和虚拟角色手机都按物品组件指向的主人读写。同一主人的多部手机会共享壁纸、应用、预设聊天、笔记和密码。编辑器预览读取该主人的资料；本地相册仍使用当前客户端的照片。</p></div>
</div>
